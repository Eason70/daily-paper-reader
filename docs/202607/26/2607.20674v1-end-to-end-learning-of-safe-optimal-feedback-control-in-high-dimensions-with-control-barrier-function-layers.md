## 摘要
我们考虑在由控制屏障函数（CBFs）强制执行硬安全约束条件下，学习高维半全局反馈控制器的问题。将CBFs纳入端到端策略训练需要将基于二次规划的安全滤波器作为优化层嵌入，但计算和微分瓶颈在很大程度上限制了先前的方法只能处理低维系统，通常最多16个状态维度。我们通过将算子拆分与最近开发的雅可比自由反向传播（JFB）方法相结合来解决这一限制，从而实现可扩展的端到端训练，同时通过CBF安全滤波器保持硬安全保证。我们使用非光滑分析技术在理论上证明了这种训练方法的合理性，并在状态和控制维度分别高达1200和400的高维多智能体非线性控制问题上展示了其有效性。

## Abstract
We consider the problem of learning high-dimensional semi-global feedback controllers under hard safety constraints enforced by control barrier functions (CBFs). Incorporating CBFs into end-to-end policy training requires embedding a quadratic-program-based safety filter as an optimization layer, but computational and differentiation bottlenecks have largely restricted prior approaches to low-dimensional systems, typically with at most 16 state dimensions. We address this limitation by combining operator splitting with the recently developed Jacobian-Free Backpropagation (JFB) method to enable scalable end-to-end training while preserving hard safety guarantees through the CBF safety filter. We justify this training methodology theoretically using nonsmooth analysis techniques and demonstrate its effectiveness on high-dimensional multi-agent nonlinear control problems with state and control dimensions up to 1200 and 400, respectively.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：通过算子分裂（Davis–Yin Splitting, DYS）求解CBF-QP投影，并结合雅可比自由反向传播（Jacobian-Free Backpropagation, JFB）进行高效的端到端梯度训练，从而避免求解大型KKT系统或展开所有迭代带来的计算负担。
- **关键技术细节**：
    - **CBF-QP安全滤波器**：对于控制仿射系统，安全约束由CBF条件`˙h(z) + α(h(z)) ≥ 0`给出，该条件关于控制输入u是仿射的。安全滤波器将名义控制uθ投影到满足该约束的凸集C(z)上，即求解`min_u ||u-uθ||^2 s.t. A(z)u ≤ b(z)`。
    - **Davis–Yin分裂（DYS）**：引入松弛变量s，将QP等价转化为两个简单集合的交集：`C1 = { (u,s): s ≥ 0 }`（非负象限）和`C2(z) = { (u,s): A(z)u + s = b(z) }`（仿射子空间）。DYS将投影分解为分别在C1和C2上的闭式投影迭代，每个迭代仅需简单阈值化和仿射投影，无需求解线性系统。定义固定点算子Tθ，其不动点y⋆对应QP的解。
    - **雅可比自由反向传播（JFB）**：在反向传播中，代替计算完整的隐式雅可比`(I - ∂Tθ/∂y)^{-1} ∂Tθ/∂θ`，直接使用近似`∂Tθ/∂θ`作为梯度。这避免了求解线性系统和存储计算图，将每个时间步的梯度计算复杂度从O((m+c)^3)降至O((m+c)p)（p为网络参数数）。JFB的近似仅在最终DYS迭代上启用一次梯度计算（Algorithm 1）。
    - **收敛性分析**：利用Clarke广义雅可比处理非光滑性，证明了DYS算子关于y是压缩的（压缩因子γ<1），从而保证不动点唯一且稳定。在此基础上，证明了JFB梯度是期望损失函数的下降方向（Theorem 11），并进一步证明连续时间梯度流可收敛到Clarke稳定点（Theorem 12）。这是首个对嵌入非光滑投影层的策略训练给出收敛性保证的工作。
- **算法流程**（文字说明）：
    1. 从初始状态分布ρ中采样一批初始状态。
    2. 对每个轨迹的每个时间步：
        - 通过策略网络uθ计算名义控制；
        - 使用DYS迭代求解CBF-QP得到安全滤波控制u⋆；
        - 在最后一步DYS迭代上启用梯度，得到JFB梯度近似；
        - 使用u⋆更新状态（执行RK4积分），累计成本。
    3. 反向传播计算JFB梯度，更新策略参数θ。

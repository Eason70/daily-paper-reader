## 摘要
我们考虑在由控制障碍函数（CBF）强制执行硬安全约束的条件下，学习高维半全局反馈控制器的问题。将CBF纳入端到端策略训练需要将基于二次规划的安全滤波器作为优化层嵌入，但计算和微分瓶颈将先前的方法主要限制在低维系统（通常最多16个状态维度）。我们通过结合算子分裂与最近开发的雅可比自由反向传播（JFB）方法来解决这一限制，从而在通过CBF安全滤波器保持硬安全保证的同时，实现可扩展的端到端训练。我们使用非光滑分析技术从理论上证明了这种训练方法的合理性，并在状态和控制维度分别高达1200和400的高维多智能体非线性控制问题上展示了其有效性。

## Abstract
We consider the problem of learning high-dimensional semi-global feedback controllers under hard safety constraints enforced by control barrier functions (CBFs). Incorporating CBFs into end-to-end policy training requires embedding a quadratic-program-based safety filter as an optimization layer, but computational and differentiation bottlenecks have largely restricted prior approaches to low-dimensional systems, typically with at most 16 state dimensions. We address this limitation by combining operator splitting with the recently developed Jacobian-Free Backpropagation (JFB) method to enable scalable end-to-end training while preserving hard safety guarantees through the CBF safety filter. We justify this training methodology theoretically using nonsmooth analysis techniques and demonstrate its effectiveness on high-dimensional multi-agent nonlinear control problems with state and control dimensions up to 1200 and 400, respectively.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将CBF-QP安全滤波器作为优化层嵌入神经网络策略，通过Davis–Yin分裂（DYS）求解投影问题，并利用雅可比自由反向传播（JFB）近似梯度，避免求解大规模线性系统，从而实现可扩展的端到端训练。

### 关键技术细节
1. **问题形式化**：
   - 考虑控制仿射系统 \(\dot{z} = f(t,z) + g(t,z)u\)，安全集由 \(h(z) \geq 0\) 定义。
   - CBF条件：\(\dot{h}(z) + \alpha(h(z)) \geq 0\)，转化为线性不等式约束 \(A(z)u \leq b(z)\)。
   - 安全滤波器：将名义控制 \(u_\theta\) 投影到可行集，即求解QP：
     \[
     u^\star_\theta = \arg\min_{u \in \mathcal{C}(z)} \frac12 \|u - u_\theta\|^2.
     \]
2. **Davis–Yin分裂（DYS）求解QP**：
   - 引入松弛变量 \(s\)，将不等式约束转化为等式约束和 \(s \geq 0\)，获得两个简单集合 \(C_1\)（非负象限）和 \(C_2(z)\)（仿射子空间）。
   - 定义DYS固定点算子 \(T_\theta\)，通过交替投影和梯度步骤迭代求解，每个子问题均有闭式解（投影到非负象限和仿射子空间），计算高效。
   - 证明DYS算子关于 \(y\) 是压缩的（压缩常数 \(\gamma < 1\)），保证固定点存在唯一。
3. **雅可比自由反向传播（JFB）**：
   - 在反向传播时，忽略隐含微分中的逆项 \((I - \partial T_\theta/\partial y)^{-1}\)，直接用 \(\partial T_\theta/\partial \theta\) 近似梯度，避免求解大规模线性系统和展开计算图。
   - 相比隐式微分（如CVXPY Layers）和自动微分（AD），JFB将每步梯度复杂度从 \(O((m+c)^3 + (m+c)^2 p)\) 降低到 \(O((m+c)p)\)（\(p\)为网络参数数量），显著减少内存和计算量。
4. **理论分析**：
   - 利用Clarke广义雅可比处理非光滑性（投影导致梯度不连续），证明对于任意Clarke子梯度，JFB梯度更新是期望下降方向。
   - 在连续时间梯度流下，证明算法渐近收敛到Clarke平稳点（满足 \(\liminf \inf_{\phi \in \partial_C \mathbb{E}[J]} \|\phi\| = 0\)）。
   - 假设包括：CBF矩阵满行秩、有界域、光滑性（部分）、JFB积分矩阵的秩和条件数控制、以及弱耦合条件（松弛变量对梯度对齐的影响有界）。

### 算法流程（文字描述）
1. 初始化策略网络参数 \(\theta\)。
2. 从初始分布 \(\rho\) 采样批次；对于每个轨迹的每个时间步：
   - 计算名义控制 \(u_\theta(t,z)\)；
   - 初始化松弛变量 \(y\)；
   - 执行DYS固定点迭代直到收敛（前向传播）；
   - 再执行一次DYS更新并启用梯度计算（用于JFB反向传播）；
   - 从收敛的 \(y\) 提取安全过滤控制 \(u^\star\)；
   - 使用数值积分（RK4）更新状态。
3. 累加运行成本和终端成本，计算批次平均损失；
4. 通过JFB计算损失对 \(\theta\) 的梯度，更新 \(\theta\)。

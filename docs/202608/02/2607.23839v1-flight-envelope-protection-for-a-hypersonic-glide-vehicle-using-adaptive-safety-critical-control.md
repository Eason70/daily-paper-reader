## 摘要
本文提出了一种面向模型不确定下高超声速滑翔飞行器（HGVs）飞行包线保护（FEP）的自适应安全关键控制框架。所提出的架构通过两种互补但不同的机制来处理输入和状态约束。在输入端，设计了一种带有校准闭环参考模型（CCRM）的自适应控制器，以适应幅值受限的控制输入和作动器饱和的影响。在此输入受限的自适应控制架构基础上，飞行包线状态约束在状态端通过基于控制障碍函数（CBFs）的基于误差的安全滤波器（EBSF）来强制执行。EBSF修改参考指令，并利用参考模型与不确定被控对象之间测量的失配在线调整可行安全集，从而在瞬态自适应过程中保持前向不变性。对DLR通用高超声速滑翔飞行器2（GHGV-2）的仿真结果表明，在幅值受限控制输入下，即使存在模型不确定性，也能保持飞行包线约束，同时实现稳定、高性能的跟踪。

## Abstract
This paper presents an adaptive safety-critical control framework for flight envelope protection (FEP) of hypersonic glide vehicles (HGVs) under model uncertainty. The proposed architecture treats input and state constraints through two complementary but distinct mechanisms. At the input end, an adaptive controller with a calibrated closed-loop reference model (CCRM) is designed to accommodate magnitude-limited control inputs and the effects of actuator saturation. Building on this input-constrained adaptive control architecture, flight envelope state constraints are enforced at the state end by an error-based safety filter (EBSF) based on control barrier functions (CBFs). The EBSF modifies the reference command and adapts the admissible safe set online using the measured mismatch between the reference model and the uncertain plant, thereby preserving forward invariance during transient adaptation. Simulation results for the DLR generic hypersonic glide vehicle 2 (GHGV-2) demonstrate stable, high-performance tracking under magnitude-limited control inputs while maintaining flight envelope constraints in the presence of model uncertainty.

**研究动机与背景**

- 高超声速滑翔飞行器（HGV）在飞行中面临强气动耦合、快速变化的流场条件、严酷的热/结构载荷以及有限的控制权限，因此飞行控制系统不仅需要实现高精度跟踪，还必须满足严苛的飞行包线约束（如攻角、载荷因子、马赫–高度走廊）。

- 自适应控制虽能处理参数不确定性，但单独的稳定性和跟踪保证无法保证学习瞬态期间满足状态约束。

## 2. 论文提出的方法论

**核心思想**

提出一个双层架构：输入端的自适应控制负责稳定跟踪和输入饱和处理，状态端的CBF安全滤波器负责飞行包线状态约束的强制执行。两层机制互补但解耦，适合过驱动的HGV系统。

**关键技术细节**

1. **输入约束处理——CCRM自适应控制器**
   - 基于线性化设计模型：`ẋ = A(σ₀)x + B(σ₀)Λ R_u(u(t))`，其中Λ是对角正定的未知控制效能矩阵，`R_u(·)`表示输入饱和函数（基于内切椭球的可达力矩集构建）。
   - 采用校准闭环参考模型（CCRM）：
     `ẋ_m = A_m x_m + B_m r* + L e_x + B_p Λ̂ Δu`
     其中 `L e_x` 项改善瞬态响应，`B_p Λ̂ Δu` 项补偿饱和扰动（Δu = R_u(u) − u）。
   - 自适应律（式IV.7–IV.9）在线更新 `Θ̂_x`、`Θ̂_r` 和 `Λ̂`，Lyapunov函数保证误差动态有界。
   - 输入饱和通过可达力矩集的内切椭球近似实现，保留命令方向，兼顾计算效率。

2. **状态约束建模**
   - 载荷因子（结构/失速边界）通过线性近似转化为攻角约束 `S_load_α`；
   - 马赫–高度走廊约束通过升力−垂直加速度关系转化为攻角约束 `S_corr_α`；
   - 最终合并为统一的临界攻角约束：`α_crit,min ≤ α(t) ≤ α_crit,max`。

3. **状态约束处理——CBF安全滤波器**
   - **SEB（静态误差缓冲）**：在CBF条件中加入固定的安全裕度Δ，确保 `x_m ∈ S_E ⊂ S`，从而 `x_p ∈ S`。但该方案始终保守。
   - **EBSF（基于误差的安全滤波器）**：将参考动态（`z_m`）与最坏情况下的被控对象动态（`z_p`）通过状态依赖插值参数 `β_j(x,e_x)` 融合进CBF不等式（式IV.23），当跟踪误差 `e_x` 小时更接近参考动态的CBF条件，误差大时更接近最坏情况条件，从而在不牺牲安全性的前提下减少保守性。
   - 采用高阶CBF（h₁₂、h₂₂）处理相对阶为2的攻角动力学。

**整体控制流程**

> 外部参考指令 → EBSF安全滤波器修正r* → CCRM自适应控制器生成u(t) → 饱和函数R_u(u) → 被控对象/参考模型 → 误差反馈至安全滤波器在线调节安全裕度。

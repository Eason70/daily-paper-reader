## 摘要
记忆对于长期运行的LLM智能体至关重要，然而现有的记忆系统主要保存交互内容，而非建模哪些智能体可以被信任以及在何种条件下可信。这一局限在多智能体系统中尤为重要，因为中心模型可能无法直接验证看似合理或相关的对等响应。我们提出了Σ-Mem，一种在线可靠性记忆，它记录单个对等体的历史能力证据以及对等体集合中的对等关系证据。两种证据均以实对称状态维护，并根据决策后的正确性反馈进行更新。通过Weyl不等式，每次事件级更新引起的谱变化是有界的，从而能够在不重新训练底层模型的情况下实现稳定的在线适应。Σ-Mem提供通用的写读接口：同一记忆可用于中心模型的残差引导、无响应对等体路由或可靠性加权投票。在五个Qwen系列模型上，Σ-Mem能够适应反事实可靠性变化，并泛化到未见过的对等体和任务域。直接记忆读取在完整OOD评估集上也优于多数投票和最佳固定对等体。此外，随着更多正确性反馈的可用，性能持续提升，表明Σ-Mem逐步积累可操作的可靠性信息。这些结果确立了可靠性记忆作为基于LLM的多智能体系统中自适应协调的可复用基础。

## Abstract
Memory is central to long-horizon LLM agents, yet existing memory systems primarily preserve interaction content rather than modeling which agents can be trusted and under what conditions. This limitation is particularly important in multi-agent systems, where a central model may be unable to directly verify plausible or correlated peer responses. We introduce $Σ$-Mem, an online reliability memory that records historical competence evidence for individual peers and peer relationship evidence across the peer set. Both forms of evidence are maintained as real symmetric states and updated from post-decision correctness feedback. By Weyl's inequality, the spectral change caused by each event-level update is bounded, enabling stable online adaptation without retraining the underlying models. $Σ$-Mem provides a general write-and-read interface: the same memory can be used for residual steering of a central model, response-free peer routing, or reliability-weighted voting. Across five Qwen-family models, $Σ$-Mem adapts to counterfactual reliability shifts and generalizes to unseen peers and task domains. Direct memory readouts also outperform majority voting and the best fixed peer over the full OOD evaluation set. Moreover, performance improves consistently as more correctness feedback becomes available, indicating that $Σ$-Mem progressively accumulates actionable reliability information. These results establish reliability memory as a reusable foundation for adaptive coordination in LLM-based multi-agent systems.

- **现有记忆系统的局限**：当前 LLM 智能体的记忆系统主要聚焦于“内容记忆”（content memory），即保存、检索和总结历史交互中说了什么、观察到了什么或尝试过什么。这种记忆在单智能体长程任务中有效，但在多智能体系统（MAS）中无法回答一个关键问题：**哪个智能体可以被信任，以及在什么条件下被信任**。
- **多智能体系统的独特挑战**：
  - 中央模型（central model）协调多个对等体（peer），需要判断的不只是对等体“说了什么”，还包括“是否应该信任该对等体处理当前任务类型”。
  - 中央模型往往无法直接验证对等体的响应：支持性证据不可得，或判断一个答案与产生它一样困难。
  - 多个对等体的一致回答可能反映的是**共享偏差或相关错误**，而非独立证据。仅靠内容记忆无法区分“独立支持”与“共同失效”。
- **核心研究问题**：如何构建一种**可靠性记忆**，持续记录每个对等体在不同任务条件下的历史可信度，并利用这种记忆辅助中央模型在信任决策上做出更好的判断？
- **论文提出的解决方案**：提出 Σ-Mem，一种**在线可靠性记忆**机制，显式建模并累积两种互补的可靠性证据：
  1. **历史能力证据**（historical competence evidence）：记录每个对等体在不同任务条件下的可信程度。
  2. **对等关系证据**（peer relationship evidence）：建模对等体之间的正确性模式关系（例如是否倾向于独立成功或共同失败）。
- **整体含义**：可靠性记忆不是响应聚合的辅助信号，而是一种**可复用的协调状态**，可以跨对等体集、任务分布和选择机制迁移，为 LLM 多智能体系统的自适应协调提供基础。

## 2. 方法论

### 2.1 核心思想

- 将可靠性记忆建模为**实对称矩阵**，利用矩阵谱理论保证在线更新的稳定性。
- 两种证据均从**决策后的外部正确性反馈**（post-decision correctness feedback）更新，无需重新训练底层模型。
- 提供通用“写-读”接口：同一个记忆状态可以支持多种协调决策，包括：
  - 对中央模型的**残差引导**（residual steering）；
  - **无响应路由**（response-free peer routing）；
  - **可靠性加权投票**（reliability-weighted voting）。

### 2.2 关键技术细节

#### 事件级记忆记录（Event-Level Σ-Mem Record）

- **对每个对等体 \(p\)**，维护对称矩阵 \(\mathbf{M}_p \in \mathbb{R}^{r \times r}\)，初始化为零矩阵。
- 每个事件 \(t\)，根据输入 \(x_t\) 计算**能力方向**（competence direction）\(\boldsymbol{\phi}(x_t) \in \mathbb{R}^r\)，满足 \(\|\boldsymbol{\phi}(x_t)\|_2 = 1\)，并获取对等体 \(p\) 的正确性标签 \(c_{p,t} \in \{+1, -1\}\)。
- 更新规则：
  \[
  \mathbf{M}_p^{(t+1)} = \gamma \mathbf{M}_p^{(t)} + \eta \, c_{p,t} \boldsymbol{\phi}(x_t) \boldsymbol{\phi}(x_t)^\top
  \]
  其中 \(\gamma \in (0,1)\) 为衰减因子，\(\eta > 0\) 为更新因子。
- 更新项为秩一对称矩阵，因此 \(\mathbf{M}_p\) 始终保持实对称。

#### 稳定性保证（Weyl 不等式）

- 利用 Weyl 不等式：\[\lambda_i(\mathbf{M} + \mathbf{E}) - \lambda_i(\mathbf{M}) \leq \|\mathbf{E}\|_2\]
  每次事件级更新相当于对记忆矩阵的一个有界对称扰动，任何单个事件不能使谱发生任意大的变化。
- **定理 1（持久证据主导噪声）**：在固定能力方向 \(\boldsymbol{\phi}_*\) 上，若对等体具有持久期望能力 \(\mu_p\)，则：
  \[
  \lambda_{\max}(\mathbf{M}_p^{(T)}) \geq \eta \mu_p \frac{1-\gamma^T}{1-\gamma} - \eta \sqrt{\frac{8\log(2/\delta)}{1-\gamma^2}}
  \]
  信号项随 \(T\) 增长并饱和至 \(\eta\mu_p/(1-\gamma)\)，噪声项不随 \(T\) 增长，信噪比 \(\mu_p \sqrt{(1+\gamma)/(1-\gamma)}\) 随 \(\gamma\) 单调递增。

#### 对等关系矩阵（Peer Relationship Matrix）

- 定义正确性向量 \(\mathbf{c}_t = [c_{1,t}, \ldots, c_{P,t}]^\top\)，并在对等体内中心化：
  \[
  q_{p,t} = c_{p,t} - \frac{1}{P}\sum_{j=1}^P c_{j,t}
  \]
- 更新关系矩阵 \(\mathbf{G}\)：
  \[
  \mathbf{G}^{(t+1)} = \gamma_G \mathbf{G}^{(t)} + \eta_G \mathbf{q}_t \mathbf{q}_t^\top,\quad \text{diag}(\mathbf{G}^{(t+1)}) = 1
  \]
- \(\mathbf{G}_{p,q} > 0\) 表示对等体 \(p\) 和 \(q\) 的正确性信号在集合内倾向于相互支持；\(\mathbf{G}_{p,q} < 0\) 表示倾向于相互对立。

#### 记忆读取与残差引导

- 决策时，计算每个对等体的读取向量：
  \[
  \mathbf{r}_{p,t} = \mathbf{M}_p^{(t)} \boldsymbol{\phi}(x_t)
  \]
- 通过可学习投影 \(\mathbf{P}\) 和标量增益 \(g\) 映射到中央模型的隐藏维度：
  \[
  \boldsymbol{\delta}_{p,t}(x_t) = g \mathbf{P} \mathbf{M}_p^{(t)} \boldsymbol{\phi}(x_t)
  \]
- 仅将引导向量注入中央模型的**上部解码器块**（\(\ell \in \{\lfloor L/2 \rfloor, \ldots, L-1\}\)），保持模型对输入的理解能力。

#### 效用评估与对等体选择

- 中央模型作为效用评估器，计算 Yes/No 似然对比：
  \[
  U_{p,t} = \log P_{\text{CM}}(\text{Yes} | x_t, a_{p,t}; \boldsymbol{\delta}_{p,t}) - \log P_{\text{CM}}(\text{No} | x_t, a_{p,t}; \boldsymbol{\delta}_{p,t})
  \]
- 对效用进行集合内标准化得到 \(z_{p,t}\)，再结合对等关系 \(\mathbf{G}\) 构建后验：
  \[
  P(\mathbf{y}_t | x_t, \mathbf{M}^{(t)}, \mathbf{G}^{(t)}) \propto \exp\left(w_u \sum_p z_{p,t} y_{p,t} + \frac{w_g}{2}\sum_{p \neq q} G_{p,q}^{(t)} y_{p,t} y_{q,t}\right)
  \]
- 选择后验正确性期望最大的对等体作为最终输出。

#### 直接读取支持其他选择机制

- **M-route**：直接选取得分 \(s_{p,t} = \boldsymbol{\phi}(x_t)^\top \mathbf{M}_p^{(t)} \boldsymbol{\phi}(x_t)\) 最大的对等体，完全不需要对等体响应。
- **M-vote**：以 \(s_{p,t}\) 作为投票权重，对产生相同规范答案（canonical answer）的对等体加权聚合。

6. **记忆随反馈累积而改善**：反馈可用性从 5% 增加到 100%，Σ-Mem 和 M-route 的准确率持续上升，证明记忆确实在累积有用的可靠性信息。
7. **CF@50 的内在模糊性**：当历史证据一半支持原偏好、一半支持反事实变化时，Σ-Mem 会忠实累积这种模糊证据，性能下降是其忠实性的体现，而非缺陷。

## 7. 优点

- **问题定位精准**：指出现有多智能体记忆系统忽视可靠性建模这一重要缺陷，并清晰区分“内容记忆”和“可靠性记忆”。
- **理论支撑扎实**：利用 Weyl 不等式为更新稳定性提供形式化保证，并给出定理 1 证明持久信号主导噪声，增强了方法的可信度。
- **设计优雅通用**：
  - 所有状态以实对称矩阵表示，更新形式简单，易于实现。
  - 训练组件在对等体间共享，增加新对等体只需分配新状态，无需修改参数。
  - 写-读接口分离，同一记忆可支持多种选择机制。
- **评估全面且设计合理**：
  - 反事实攻击场景能够清晰检验记忆对可靠性变化的敏感性。
  - 同时验证对未见对等体和未见过任务域的泛化。
  - 包含多种对照方法（base、majority、best-fixed、oracle、Bayesian B1）。
- **洞察深刻**：通过 CF@50 上的表现揭示记忆“忠实性”与“模糊证据”之间的张力，并指出未来方向是自适应平衡历史与当前证据的读取方式。

## 8. 不足与局限

- **算力与资源信息缺失**：全文未提供任何 GPU 型号、数量、训练时长或能耗数据，不利于复现评估和成本估算。
- **模型覆盖狭窄**：
  - 中央模型仅来自 Qwen 系列，缺乏跨模型族验证；
  - 对等体模型均为中小规模（≤7B），大对等体（70B+）下的效果未知。
- **对等体选择机制较简单**：对等体固定按领域分配（一个数学、一个 RAG、一个代码），未采用更丰富的对等体混合。
- **缺乏超参数敏感性分析**：对 γ、η、w_u、w_g 等关键超参数没有做系统消融，读者不知道它们的稳定性如何。
- **CF@50 的退化未被解决**：论文将其解释为记忆忠实性的体现，但未提出缓解该问题的实际方法，仅作为未来方向提及。
- **决策时间成本未讨论**：残差引导需要对每个候选对等体运行一次中央模型（Yes/No 评估），计算开销远高于直接路由；论文未提供效率对比。

- **安全性与对抗鲁棒性未讨论**：如果对等体被恶意操纵、提供误导性反馈，或外部攻击者污染正确性标签，Σ-Mem 的在线更新机制可能被毒化，导致记忆系统累积错误信任信号。论文未分析标签噪声、对抗性反馈、延迟反馈等情况下的表现，也未设计防御机制。

- **对等体决策的独立性假设过强**：论文通过中心化处理尝试缓解对等体间的相关性，但未显式检验对等体是否独立工作。若对等体共享训练数据或模型族，其错误模式天然相关，此时对等关系矩阵可能将“共同偏差”误判为“相互支持”，削弱可靠性判定的有效性。

- **评估场景仍偏静态**：尽管引入了 CF 反事实攻击，但 CF 只是对“谁是最佳对等体”的交换比例进行控制，并未模拟真实动态环境中对等体能力随时间的缓慢漂移、周期性波动或突然失效等非平稳情形。Σ-Mem 的指数衰减机制能否适应这种连续变化，论文未提供证据。

- **记忆可解释性不足**：论文展示了记忆矩阵如何提升决策，但未阐明矩阵特征向量或特征值对应何种“能力方向”。中央模型为何认为某对等体在某个方向可靠，依然是一个黑盒，不利于在关键场景中审计和纠错。

## 9. 总结与展望

Σ-Mem 以“可靠性记忆”为核心概念，通过在线累积历史能力证据和对等关系证据，为 LLM 多智能体系统的信任决策提供了一种轻量、通用且具备理论依据的解决方案。其矩阵谱理论保证了更新的稳定性，灵活的写-读接口使其能适配选择、路由、投票等多种协调机制，并且对未见对等体和未见过任务域展现出良好的泛化能力。

然而，该方法在资源透明度、模型族覆盖、超参数鲁棒性、对抗安全性和动态环境适应性方面仍有明显不足。未来方向至少包括：对等体能力时序漂移的自适应遗忘、基于交互反馈的主动验证、对抗性反馈防御，以及更细粒度的可解释信任分析。

总体而言，Σ-Mem 提出的可靠性记忆概念拓展了多智能体系统记忆研究的边界，为中央模型与对等体之间的信任建模提供了一条新颖且实用的路径，值得后续研究者在更广泛场景中加以验证和扩展。

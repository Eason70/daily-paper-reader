## 摘要
大型语言模型（LLM）使智能体能够自主推理、规划和调用工具。近期系统越来越多地将这些智能体组织为相互连接的专业化节点图。尽管基于图的编排支持灵活的分解与协调，但它带来了一个关键挑战：	extbf{注意力分配}。随着工作流增长，现有方法往往统一执行图组件，在无关或低影响任务上浪费资源。我们提出	extbf{注意力编排}（Attention Orchestration），一种将Transformer式注意力从词元表示扩展到工作流级智能体协调的范式。我们的框架	extbf{自适应目标感知注意力编排}（AGAO）基于用户目标、图依赖和计算约束动态估计智能体重要性。AGAO结合三个组件：（1）目标感知注意力，衡量用户目标与智能体能力之间的语义相关性；（2）拓扑感知注意力，建模智能体图中的结构依赖；（3）资源感知注意力，在异构智能体间分配预算和执行优先级。这些机制共同将静态智能体图转化为自适应系统，将计算集中在目标关键推理路径上。在多种多智能体工作负载上的实验表明，与现有基于图的执行策略相比，AGAO在提升任务有效性的同时，减少了不必要的计算、延迟和词元消耗。我们的工作确立了	extbf{注意力工程}（Attention Engineering）作为可扩展、智能多智能体系统的一个研究方向。代码：https://github.com/MingzhouFan97/AGAO。

## Abstract
Large language models (LLMs) enable autonomous agents for reasoning, planning, and tool use. Recent systems increasingly organize these agents as graphs of specialized, interconnected nodes. Although graph-based orchestration supports flexible decomposition and coordination, it creates a key challenge: \textbf{attention allocation}. As workflows grow, existing approaches often execute graph components uniformly, wasting resources on irrelevant or low-impact tasks. We introduce \textbf{Attention Orchestration}, a paradigm that extends Transformer-style attention from token representations to workflow-level agent coordination. Our framework, \textbf{Adaptive Goal-aware Attention Orchestration (AGAO)}, dynamically estimates agent importance based on user objectives, graph dependencies, and computational constraints. AGAO combines three components: (1) goal-aware attention, measuring semantic relevance between user goals and agent capabilities; (2) topology-aware attention, modeling structural dependencies in agent graphs; and (3) resource-aware attention, allocating budgets and execution priorities across heterogeneous agents. Together, these mechanisms transform static agent graphs into adaptive systems that focus computation on goal-critical reasoning paths. Experiments across diverse multi-agent workloads show that AGAO improves task effectiveness while reducing unnecessary computation, latency, and token consumption compared with existing graph-based execution strategies. Our work establishes \textbf{Attention Engineering} as a direction for scalable, intelligent multi-agent systems. Code: https://github.com/MingzhouFan97/AGAO.

## 2. 方法论

- **核心思想**：提出 **AGAO（Adaptive Goal-aware Attention Orchestration，自适应目标感知注意力编排）**，在用户目标与多智能体图执行之间引入注意力量驱动的执行层，将智能体视为可动态选择的计算单元，而非固定工作流算子。
- **三大互补注意力机制**：
  - **目标感知注意力（Goal-aware Attention）**：衡量用户目标与智能体能力之间的语义相关性。将目标编码为查询向量 Qg，智能体表示（能力描述 + 历史 + 状态）投影为键/值向量，计算缩放点积注意力得到目标层注意力分布。
  - **拓扑感知注意力（Topology-aware Attention）**：引入图结构依赖，通过图偏置项 BG 加入注意力计算；同时用结构影响分数（入度、出度、关键路径贡献）捕捉全局执行影响力，避免纯语义剪枝破坏必要依赖路径。
  - **资源感知注意力（Resource-aware Attention）**：将融合后的注意力分数转化为具体执行策略——模型路由（高注意力分配大模型，低注意力分配小模型）、Token 预算按指数分配、执行优先级调度。
- **自适应图路由（Adaptive Graph Routing）**：注意力状态在执行中随中间反馈动态更新，α^{t+1} = Φ(α^t, o^t, G, q)，综合目标、拓扑、反馈三类信号；节点可根据更新后的注意力分数被激活、挂起或剪枝。
- **数学形式**：整体优化目标为最大化任务质量并最小化计算成本与延迟：max_π J(π) = Q(y,q) − λ₁C(π) − λ₂L(π)。
- **算法流程**：初始化执行状态与注意力分布 → 编码用户目标 → 循环执行：计算目标感知注意力 → 计算拓扑感知注意力 → 融合注意力信号 → 分配计算资源 → 选择活跃节点 → 执行 → 观察反馈 → 更新注意力与图状态 → 聚合输出。

## 3. 实验设计

- **数据集/场景**：
  - **MBPP**：8 个编程任务，报告 pass@1。
  - **HotpotQA**：8 个多跳问答任务，报告 token 级 F1。
  - 每个任务使用手工指定的 9 节点图（编程图为规格分析、实现、测试、调试、审查、定稿等角色；问答图为分解、检索、证据选择、推理、验证、定稿等角色）。
- **基准与对比策略**（5 种执行策略）：
  - Random：依赖有效、固定种子的随机路由。
  - Static：按固定图顺序执行所有依赖有效节点。
  - Semantic：基于词法重叠选择节点。
  - MoE-style：固定混合词法相关性 + 拓扑分数。
  - AGAO：词法目标相关性 + 拓扑分数 + 规则反馈，支持跳过低分节点并路由不同模型能力等级。
- **额外指标**：活跃节点数、累计智能体时间（累计各节点执行时间，非端到端延迟）、gateway 返回的输入/输出 token 数。
- **消融实验**：AGAO、AGAO w/o Goal、AGAO w/o Topology、AGAO w/o Resource、AGAO semantic-only，统一在每套 8 个任务上报告质量、节点数、累计时间。

## 6. 主要结论与发现

- AGAO 在 MBPP 上 pass@1 达到 0.875（7/8），高于 MoE-style（0.750）、Static（0.625）、Random/Semantic（0.500）。
- 在 HotpotQA 上，AGAO 的 F1 为 0.340，优于 Static（0.319）、Random（0.285）、Semantic（0.244），但**低于 MoE-style（0.417）**，说明其效果依赖于工作负载类型。
- **效率收益最突出**：相对 Static，AGAO 在 MBPP 和 HotpotQA 上分别减少 27.8% 与 19.4% 的活跃节点数，累计智能体时间分别降低 56.0% 与 50.3%。
- Token 方面：AGAO 输入 token 更高（反映额外路由与上下文构建开销），但输出 token 大幅减少；由于输出 token 计价高于输入 token（文中称 6 倍），总体更经济。
- 消融显示：完整 AGAO 在质量与效率间最均衡；单独移除某一组件虽然可能提升单一指标，但会在另一任务维度产生明显代价（如移除目标感知使 MBPP 提高但 HotpotQA F1 下降且 QA 时间翻倍；移除资源路由使 MBPP pass@1 从 0.875 跌至 0.250）。

## 7. 优点

- **概念创新性强**：将"注意力"从表示学习层面提升到智能体协作的执行编排层面，提出 Attention Engineering 新方向，具有较强启发意义。

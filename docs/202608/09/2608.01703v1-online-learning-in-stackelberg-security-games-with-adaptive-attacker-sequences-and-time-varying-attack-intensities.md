## 摘要
本研究探讨了在具有时变攻击强度的重复Stackelberg安全游戏中进行无遗憾在线学习的问题。我们构建了一个扩展的安全游戏，其中攻击者可能选择多个目标，并在乐观打破平局规则下推导出精确的混合整数线性规划预言机。在完全信息反馈下，该预言机与跟随扰动领导者算法相结合，针对非预期序列（具有时变的跟随者数量、攻击强度和攻击者类型）实现了期望的$\mathcal{O}(\sqrt{T})$遗憾界。在强盗反馈下，我们考虑多个跟随者共享固定攻击者类型的情况，并采用重心生成器构造从聚合攻击观测中重建效用估计，获得了期望的$\mathcal{O}(T^{2/3})$遗憾界。大量模拟实验证明了我们的方法在完全和部分信息反馈下的鲁棒性和有效性。

## Abstract
This work studies no-regret online learning in Repeated Stackelberg Security Games with time-varying attack intensities. We formulate an extended security game in which an attacker may select multiple targets and derive an exact mixed-integer linear programming oracle under a optimistic tie-breaking rule. Under full-information feedback, the oracle is integrated with Follow-the-Perturbed-Leader and yields expected $\mathcal{O}(\sqrt{T})$ regret against non-anticipating sequences with time-varying follower numbers, attack intensities, and attacker types. Under bandit feedback, we consider multiple followers sharing a fixed attacker type and use a barycentric-spanner construction to reconstruct utility estimates from aggregate attack observations, obtaining expected $\mathcal{O}(T^{2/3})$ regret. Extensive simulations demonstrate the robustness and effectiveness of our approach under full and partial information feedback.

## 1. 核心问题与整体含义

论文研究的是**重复 Stackelberg 安全博弈（Repeated Stackelberg Security Games, RSSG）中的在线学习问题**，其核心动机如下：

- **经典模型假设与现实差距**：现有研究通常假设攻击者每次只攻击单个目标、攻击容量固定、攻击者序列固定不变。但在网络安全（如 DDoS 多服务器同时攻击）、物理安全（如偷猎团伙季节性地调整狩猎规模）等真实场景中，攻击者的攻击强度（同时攻击的目标数量）、攻击者数量、攻击者类型都会随时间动态变化，且可能是**对抗性**演化的。
- **打破经典最优响应结构**：时变攻击强度破坏了经典 regret 最小化框架依赖的时不变最优响应结构，导致传统方法失效。
- **研究目标**：设计使防御者在面对这类动态演化的攻击者时，能够自适应学习并最小化累积遗憾（regret）的算法框架。

## 2. 方法论

论文的核心方法分为三部分：

### 2.1 扩展博弈模型与 MILP 预言机
- 扩展传统 SSG，允许攻击者在每轮选择 **\(l\) 个目标**同时攻击（攻击强度 \(l\) 时变）。
- 采用**乐观打破平局规则**（ties 按防御者效用递减、再按目标索引升序处理），明确了攻击者最优响应的唯一性。
- 通过引入二元决策变量 \(h_{j,l}\)、辅助变量 \(z_{j,l}\)（McCormick 线性化）和阈值变量 \(\tau_l\)，将双层优化问题转化为**单层精确 MILP（公式 2 和 3）**，使用 Big-M 线性化（\(B=2\)）编码攻击者最优响应条件。
- 该 MILP 作为在线学习算法的优化预言机，可扩展到多攻击者类型（\(K\) 类）和多种攻击强度（\(1,\dots,F\)），求解多类型场景下的最优防御策略。

### 2.2 完全信息反馈下的 FPL 算法（Algorithm 1）
- **问题**：确定性策略（如 Follow-the-Leader）会暴露防御规律，被对抗性攻击者利用，导致线性遗憾（附录 B/C/D 构造了具体反例）。
- **方法**：采用 **Follow-the-Perturbed-Leader（FPL）** 框架，在每轮对经验计数矩阵加入均匀随机扰动 \(\epsilon(t) \sim U[0, 1/(\delta\sqrt{t})]^{K\times F}\)，然后调用 MILP 预言机求解扰动后的最优策略。
- **理论保证（定理 1）**：对任意非预期攻击者序列，期望遗憾界为：
  \[
  \mathbb{E}[R(T)] \le 4\delta F C \sqrt{T} + \frac{KF(F+1)\sqrt{T}}{\delta}
  \]
  优化 \(\delta\) 后得：
  \[
  \mathbb{E}[R(T)] \le 4\sqrt{KCF^2(F+1)T} = \mathcal{O}(\sqrt{T})
  \]

### 2.3 部分信息（Bandit）反馈下的重心跨度重建算法（Algorithm 2）
- **设定**：多个跟随者共享固定攻击类型 \(\alpha\)，强度各自变化；防御者每轮只观测到**聚合的攻击目标计数**，不知道具体跟随者数量和强度。
- **关键思想**：
  1. 将策略空间按攻击者的最优响应划分为若干**凸多胞形** \(P(\sigma)\)；
  2. 利用**重心跨度（Barycentric Spanner）** 构造一组基向量 \(\{b_j\}\)，使任意攻击响应指示向量都可表示为基向量的有界线性组合；
  3. 在每个时间块内随机抽取少量时步进行探测，估计基向量的攻击频率，再通过线性组合**无偏重建**所有策略的效用（Proposition 2、Lemma 1）。
- 将重建的效用估计输入 **Polynomial Weights（PW）算法**更新策略分布。
- **理论保证（定理 2）**：期望遗憾界为：
  \[
  \mathbb{E}[R(T)] \le 3CF\,T^{2/3}(\log|V|)^{1/3}|B|^{1/3} = \mathcal{O}(T^{2/3})
  \]

## 6. 主要结论与发现

1. **精确 MILP 预言机有效**：通过 Big-M 线性化和嵌套约束，能在乐观打破平局规则下精确求解强度约束的最优响应，为在线学习提供计算基础。
2. **FPL 实现完全信息下的无遗憾学习**：对非预期的时变跟随者数量、攻击强度和异构类型序列，期望遗憾为 \(\mathcal{O}(\sqrt{T})\)。这是首个在该统一设定下获得无遗憾保证的工作。
3. **重心跨度解决部分信息学习**：在 bandit 反馈下，仅凭聚合攻击计数即可重建全信息效用估计，实现 \(\mathcal{O}(T^{2/3})\) 的遗憾界，是该设定下的首个无遗憾保证。
4. **确定性策略会被对抗性攻击者利用**：附录 B–F 构造了多个反例，演示了 Follow-the-Leader 策略在线性时间内被欺骗，累积线性遗憾，验证了加入扰动（FPL）的必要性。
5. **忽略攻击强度会导致次优**：Baseline 2 因未建模时变攻击强度而优化错误目标，在线性遗憾（对抗设定）或收敛到次优策略（随机设定）。

## 7. 优点

- **理论贡献完整**：在统一的框架下同时处理多跟随者、多类型、时变攻击强度以及对抗性攻击者序列，填补了现有工作的空白（既有工作要么假设固定攻击容量，要么假设随机分布）。
- **MILP 预言机设计精巧**：通过嵌套约束 \(h_l \ge h_{l-1}\) 实现了强度变化的单调一致性，避免了变量爆炸；Big-M 线性化保证了精确性而非近似。
- **算法集成合理**：FPL 与 MILP 天然契合（FPL 只需要离线优化预言机），保证次线性遗憾的同时保留计算可行性。
- **重心跨度方法创新性强**：将多臂赌博机的探索问题转化为基于几何结构的基向量估计问题，在仅观测聚合攻击频率的条件下实现了无偏效用重建，理论上优雅且可操作。
- **对抗性反例构造严谨**：附录中用精确的数学构造（如 13 轮循环、6 轮循环、3 轮循环）展示了确定性策略的脆弱性，有力地支撑了扰动方法的必要性。

## 8. 不足与局限

- **bandit 设定限制较多**：仅支持**固定攻击者类型**（多个跟随者共享一种类型），不支持异构类型的 bandit 学习，适用范围受限；作者也将其列为未来工作。
- **计算复杂度偏高**：MILP 的最坏情况复杂度为 \(\mathcal{O}(N^{KF+1}KF)\)，虽然形式上是多项式，但随攻击者类型数 \(K\) 和最大强度 \(F\) 增长很快，大规模场景下可能难以实时求解。
- **实验规模有限**：模拟使用的目标数（\(N=5\)）和类型数（\(K=5\)）偏小，没有展示算法在大规模真实安全场景（如机场巡逻、网络节点保护）中的可扩展性；同时缺少消融实验来验证算法对关键超参数（\(\delta\)、\(Z\) 等）的敏感性。

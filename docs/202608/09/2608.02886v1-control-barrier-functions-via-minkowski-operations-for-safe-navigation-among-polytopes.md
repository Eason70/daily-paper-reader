## 摘要
在机器人学中，安全地在多面体环境中导航同时尊重底层系统的动力学、控制和精确几何形状是一个挑战。控制障碍函数通过使安全集前向不变来综合安全控制策略，但许多现有的基于控制障碍函数的方法使用保守的平滑形状（如球体或椭圆体）来近似多面体，以获得显式可微的距离函数。在本文中，我们为多面体机器人和多面体障碍物提出了一种精确的符号距离函数公式，并将其与非光滑控制障碍函数集成。利用闵可夫斯基运算，所提出的方法通过在无碰撞（正号）和碰撞（负号）两种情况下的伴随凸规划计算精确的符号距离函数。此外，通过利用二维闵可夫斯基运算的便捷几何性质以及两个伴随凸规划的最优性条件，我们通过敏感性分析推导出精确符号距离函数梯度的统一解析表达式。精确的旋转梯度进一步揭示了一类先前被掩盖的局部极小值，这些极小值由几何与非完整运动学之间的耦合引起。我们通过一个纯平动案例和三个涉及独轮车模型的场景（包括从不安全初始状态恢复以及单障碍物和多障碍物避障）证明了所提出框架的有效性。与基线方法的比较突显了所提出的框架如何实现非保守的机动和安全恢复。

## Abstract
Safely navigating polytopic environments while respecting the dynamics, control, and exact geometry of the underlying system is a challenge in robotics. Control barrier functions (CBFs) synthesize safe control policies by rendering the safe set forward invariant, but many existing CBF-based methods approximate polytopes using conservative smooth shapes, such as spheres or ellipsoids, to obtain explicit differentiable distance functions. In this article, we propose an exact Signed Distance Function (SDF) formulation for a {\it polytopic} robot and {\it polytopic} obstacles and integrate it with nonsmooth CBFs. Leveraging Minkowski operations, the proposed method computes the exact SDF via companion convex programs in both the collision-free (positive-sign) and in-collision (negative-sign) cases. Furthermore, by exploiting the convenient geometric properties of 2D Minkowski operations and the optimality conditions of the two companion convex programs, we derive a unified analytical expression for the gradient of the exact SDF via sensitivity analysis. The exact rotational gradient further reveals a previously masked class of local minima induced by the coupling between geometry and nonholonomic kinematics. We demonstrate the effectiveness of the proposed framework through a pure-translation case and three scenarios with unicycle models involving recovery from an unsafe initialization and single- and multiple-obstacle avoidance. Comparisons with baseline methods highlight how the proposed framework enables non-conservative maneuvers and safety recovery.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 利用闵可夫斯基运算（Minkowski operations）在“闵可夫斯基差空间”（MD-space）中构造机器人与障碍物之间的**精确SDF**：
  - 无碰撞时，SDF为正，等于原点到配置障碍物（CO）的最小距离；
  - 碰撞时，SDF为负，等于原点相对CO的穿透深度。
- 将SDF作为非光滑CBF（NCBF）的安全函数，并结合CLF通过二次规划求解控制输入，形成CLF-NCBF-QP框架。

### 关键技术细节
- **MD-space与配置障碍物**：机器人缩为原点，障碍物映射为CO：\(O_c = O \oplus (-R)\)；原点到CO的距离/穿透深度即等价于机器人-障碍物的SDF。
- **两个伴随凸规划**：
  1. **最小距离QP（dist-QP）**：\(\min \|z\|_2^2 \quad \text{s.t. } A^c(x) z \le b^c(x)\)，用于无碰撞情形，解为原点在CO上的唯一投影。
  2. **穿透深度LP（depth-LP）**：\(\max_{s\in\mathbb{R}_+} s \quad \text{s.t. } \|a_i^c(x)\|_2 s \le b_i^c(x)\)，用于碰撞情形，其最优值 \(s^*\) 为原点到CO最近超平面的距离。
- **统一梯度计算**：
  - 通过KKT最优性条件的灵敏度分析（diffOpt / IFT），利用价值函数导数（\(\nabla_x f_0(z^*) = \partial L/\partial x\big|_{\xi^*}\)）导出统一梯度形式：
    \[
    \frac{\partial h}{\partial x} = \frac{(\lambda_I^*)^\top}{2\|z^*\|_2} \left( \frac{\partial A_I^c}{\partial x} z^* - \frac{\partial b_I^c}{\partial x} \right)
    \]
    该式同时适用于dist-QP和depth-LP（通过构造LP诱导的“伪QP乘子”）。
  - 针对SE(2)配置，分别推导平移梯度（\(\partial h/\partial p\)，满足Eikonal方程、单位范数）和旋转梯度（\(\partial h/\partial \theta = (\partial h/\partial p) \ell^\perp\)），其中 \(\ell = r^* - p\) 为机器人侧见证点向量。
  - 接触情况（\(z^*=0\)）通过取安全/碰撞两侧极限得到一致梯度形式。
- **控制器合成**：在每个时刻，先根据碰撞状态求解dist-QP或depth-LP评估SDF，识别（近）活跃约束集；然后求解CLF-NCBF-QP获得控制输入 \(u^*(x)\)：
  \[
  \min_{u,\delta} \; u^\top H u + p\delta^2, \quad \text{s.t. CLF约束与NCBF约束}
  \]
  其中NCBF约束使用广义梯度的充分条件（对每个近活跃分支逐一施加）。
- **非光滑CBF理论**：由于SDF仅是局部Lipschitz的，采用广义梯度（Clarke）和Filippov解的概念，通过集值内积条件保证安全集前向不变。

- **精确SDF可行且有效**：通过MD-space中的两个伴随凸规划，可以在不近似几何的前提下精确计算多面体间的SDF，并统一处理无碰撞、接触和穿透三种情况。

- **非保守性与安全恢复能力**：与基于光滑近似或保守下界的CBF方法相比，本文方法生成的轨迹更短、更贴近障碍物，且能在机器人初始位于碰撞状态时自动安全恢复。

- **算法实用性**：CLF-NCBF-QP可在200 Hz下实时运行，适合作为安全过滤器，但不应替代全局规划器。

## 7. 优点：方法或实验设计上的亮点

- **几何精确性**：完全避免了多面体的光滑近似或保守下界，直接对精确几何建模，从根本上消除过度保守问题。

- **闭式梯度**：基于KKT/IFT推导出解析梯度，避免近似梯度和自动微分，提高数值稳定性和计算效率（相对一般隐式梯度方法）。
- **非光滑CBF的正确处理**：使用广义梯度与Filippov解理论，给出NCBF的充分条件，并在实现中通过“近活跃集”平滑处理非光滑点。
- **发现新现象**：GKC局部极小值的识别不仅有理论意义（揭示几何与非完整动力学耦合），也为后续系统设计与障碍规避策略提供警示。
- **对比实验有针对性**：与LSE光滑方法和对偶MDF方法对比，清晰展示非保守性和鲁棒性优势。

## 摘要
平均场控制障碍函数（MF-CBFs）通过对智能体分布的约束来保障集群安全。此前的公式，包括在随机覆盖和牧羊中的应用，使用一阶微分不等式。这些方法无法直接施加这样的约束：其障碍函数的一阶导数不显含控制。因此，我们发展了高阶 MF-CBF 理论；该理论通过高阶微分不等式确保障碍泛函的正性，正如其有限维对应形式那样。更具体地说，我们引入平均场安全泛函的相对阶概念，并建立了一个用于计算其高阶导数的解析框架。此外，对于互相关和自相关泛函的实际例子，我们表明沿平均场动力学的重复微分具有结构保持性，并归结为核递推。作为示例，我们将高阶 MF-CBF 应用于双积分器集群跟踪与避障问题，其中仅位置约束会产生相对阶为二的 MF-CBF。

## Abstract
Mean-field control barrier functions (MF-CBFs) enforce swarm safety through constraints on the agents' distribution. Previous formulations, including applications to stochastic coverage and shepherding, use first-order differential inequalities. These cannot directly enforce constraints whose barrier functions yield control-free first derivatives. Thus, we develop the theory of higher-order MF-CBFs, which ensures the positivity of the barrier functionals through higher-order differential inequalities, as in their finite-dimensional analogs. More specifically, we introduce the notion of relative degree for mean-field safety functionals and develop an analytic framework for computing their higher-order derivatives. Moreover, for practical examples of cross-correlation and self-correlation functionals, we show that repeated differentiation along mean-field dynamics is structure-preserving and reduces to kernel recursions. As an illustration, we apply higher-order MF-CBFs to double-integrator swarm tracking and avoidance problems, where position-only constraints lead to MF-CBFs of relative degree two.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：控制障碍函数（CBF）通过构造一个非负的障碍函数来编码安全性，并沿系统动力学保持其非负性，从而在每个时刻定义一个“安全控制集”，控制器只需将名义控制投影到该集合即可。这一思想已被广泛应用于有限维控制系统。
- **集群场景**：对于大量同质智能体组成的集群，目标通常涉及聚合行为（覆盖、跟踪、占据指定区域等），因此自然地将集群建模为状态空间中的概率分布，其控制与动力学在概率测度空间上描述，即**平均场控制**（Mean-Field Control）问题。
- **已有工作**：MF-CBF 框架由 Fung 与 Nurbekyan 在 2025 年提出，并随后被扩展到随机智能体的覆盖与牧羊问题。这些工作均使用**一阶微分不等式**来保持安全泛函的非负性。
- **核心痛点**：当控制不出现在安全泛函的一阶导数中时，一阶 MF-CBF 无法直接施加约束。典型例子是：加速度（控制）首先通过**二阶导数**影响位置约束，因此仅位置约束天然对应相对阶为二的 MF-CBF。

- **整体含义**：这是首个考虑高阶 MF-CBF 的工作，扩展了集群安全约束的可处理范围，使仅位置约束的集群跟踪与避障成为可解问题。

### 2.1 基础机制（Lemma 1 与 Lemma 2）

- **Lemma 1（非负性传播）**：给定光滑函数 h₀(t)，定义递归 h_k(t) = ḣ_{k-1}(t) + α_k(h_{k-1}(t))，其中 α_k 为扩展 class-K∞ 函数。若初始条件 h_k(0) ≥ 0（0 ≤ k < r）且 h_r(t) ≥ 0 对所有 t ≥ 0 成立，则 h_k(t) ≥ 0（0 ≤ k < r），特别地 h₀(t) ≥ 0。
- **Lemma 2（结构分解）**：将 h_k 表示为
  h_k(t) = h₀^{(k)}(t) + B_k(h₀(t), …, h₀^{(k-1)}(t))，
  其中 B_k 仅依赖于 α_k 函数，可独立于状态动力学与 h₀ 预先计算。该恒等式表明：**控制首次出现在 (h_k) 中的时刻，恰好等于控制首次出现在 (h₀^{(k)}) 中的时刻**，因此计算 (h_k) 本质归结为计算 (h₀^{(k)})。

### 2.2 平均场动力学与泛函微分

- **个体动力学**：ẋ = f(t,x) + g(t,x)u(t,x)，x ∈ ℝ^d，u(t,x) ∈ U ⊆ ℝ^m 为反馈控制。
- **密度演化**：集群概率分布 ρ_t 满足连续性方程
  ∂_t ρ_t + ∇·(ρ_t(f + g u)) = 0。
- **安全泛函**：目标为选择控制使得 h₀(t) = F(t, ρ_t) ≥ 0。
- **关键算子**：
  - 第一变分：d/dh F(t, ρ + hη)|_{h=0} = ∫ δ_ρF(t,ρ)(x)η(x) dx；
  - 密度梯度：D_{Wρ}F(t,ρ)(x) = D_x[δ_ρF(t,ρ)(x)]；
  - **漂移算子**：L_f F(t,ρ) = ∂_t F(t,ρ) + ∫ D_{Wρ}F(t,ρ)(x) f(t,x) ρ(x) dx。
- **链式法则**：dF/dt = L_f F + ∫ D_{Wρ}F g u ρ_t dx，将漂移贡献与控制项分离。

### 2.3 相对阶与高阶导数（Definition 1 与 Proposition 1）

- **相对阶定义**：泛函 F 相对阶为 r ≥ 1，若对 0 ≤ k ≤ r-2 有
  D_{Wρ}[L_f^k F](t,ρ)(x) g(t,x) ρ(x) = 0（对所有 (t,ρ,x)），
  而 k = r-1 时该表达式对某些 (t,ρ,x) 非零。
- **Proposition 1**：若 F 相对阶为 r，则
  - 对 0 ≤ k < r：h₀^{(k)}(t) = L_f^k F(t, ρ_t)；
  - 第 r 阶：h₀^{(r)}(t) = L_f^r F(t, ρ_t) + ∫ D_{Wρ}[L_f^{r-1}F](t,ρ_t) g u ρ_t dx。
  - 辅助函数 h_k = L_f^k F + B_k(F, …, L_f^{k-1}F)（k < r），而 h_r 关于控制是仿射的（即使 α_k 非线性）。

### 2.4 安全控制集与安全性保持（Theorem 1）

- **安全控制集**：
  K_CBF(t,ρ) = { u ∈ U : L_f^r F + B_r(F, …, L_f^{r-1}F) + ∫ D_{Wρ}[L_f^{r-1}F] g u ρ dx ≥ 0 }。
  该集合对控制场施加**一个仿射不等式**（外加 u(x) ∈ U 的可行性限制）。
- **Theorem 1**：若初始密度 ρ₀ 满足 L_f^k F(0,ρ₀) + B_k(…) ≥ 0（0 ≤ k < r），且控制满足 u(t,·) ∈ K_CBF(t,ρ_t) 对所有 t ≥ 0 成立，则 F(t,ρ_t) ≥ 0 对所有 t ≥ 0 成立。

### 2.5 相关泛函的核递推（Proposition 2）

- **互相关泛函**：R(t,ρ) = ∫∫ k(t,x,y) ρ(x) ρ*_t(y) dx dy；
- **自相关泛函**：S(t,ρ) = ∫∫ h(t,x,y) ρ(x) ρ(y) dx dy（h 关于 x,y 对称）；
- **障碍形式**：F = σ(ε - R)，F_s = ε_s - S，σ ∈ {−1, 1}。σ = 1 限制与障碍群的接近度，σ = −1 维持与目标群的接近度；自相关上界限制集群拥挤。
- **核递推**：K₀ = k，A₀ = h，
  K_{j+1} = ∂_t K_j + D_x K_j f(t,x) + D_y K_j f*(t,y)，
  A_{j+1} = ∂_t A_j + D_x A_j f(t,x) + D_y A_j f(t,y)。
- **结构保持性**：L_f^j R 仍为互相关形式（核为 K_j），L_f^j S 仍为自相关形式（核为 A_j 且保持对称）。这使高阶导数计算归结为**核递推**，避免在概率测度空间中进行复杂的高阶变分。

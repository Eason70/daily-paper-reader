## 摘要
安全全身运动对于在非结构化环境中部署人形机器人至关重要。现代人形控制通常将参考设定与执行分离，由规划器、遥操作者或运动生成器提供参考，强化学习策略通过动力学可行的全身控制来跟踪该参考。运行时安全滤波器，如控制屏障函数（CBFs），提供了一种有前景的方法，通过对跟踪器输出进行干预来强制执行新引入的约束。然而，我们表明，将跟踪策略与安全滤波器独立处理会引发根本性失配，因为滤波会同时改变所执行的动作和诱导的状态分布。我们通过案例研究来考察这一策略-滤波器接口，这些案例分别隔离动力学、目标和信息失配，揭示其根本原因，并利用这些洞见开发了 CoFiT（Constrained Filter-aware Tuning，约束滤波器感知微调），一种针对预训练跟踪器的滤波器感知微调方法。在多样化的约束场景中，相较于仅使用滤波器的训练，CoFiT 在 TWIST2 上将违反约束时间减少 91%，在 SONIC 上减少 21%，同时需要更小的安全滤波器修正。在 Unitree G1 硬件上，CoFiT 将 TWIST2 的违反约束时间减少 83%，并在无需操作员干预的情况下完成每次试验，而基线试验中有 50% 需要操作员停止。总之，这些结果为策略-滤波器交互提供了可操作的洞见，并为将学习型跟踪器与运行时安全滤波器集成确立了设计原则。

## Abstract
Safe whole-body motion is essential for deploying humanoid robots in unstructured environments. Modern humanoid control commonly separates reference specification from execution, with a planner, teleoperator, or motion generator providing a reference that a reinforcement-learning policy tracks through dynamically feasible whole-body control. Runtime safety filters, such as control barrier functions (CBFs), offer a promising approach for enforcing newly introduced constraints via interventions on the tracker's outputs. We show, however, that treating the tracking policy and safety filter independently induces fundamental mismatches, as filtering alters both the executed actions and the induced state distribution. We study this policy-filter interface through case studies that isolate dynamics, objective, and information mismatches, highlight their root causes, and use these insights to develop CoFiT (Constrained Filter-aware Tuning), a filter-aware fine-tuning method for pretrained trackers. Across diverse constraint scenes, CoFiT reduces violation time relative to filter-only training by 91% on TWIST2 and 21% on SONIC, while requiring smaller safety filter corrections. On Unitree G1 hardware, CoFiT reduces violation time by 83% for TWIST2 and completes every trial without operator intervention, whereas 50% of baseline trials require an operator stop. Together, these results provide actionable insights into policy-filter interactions and establish design principles for integrating learned trackers with runtime safety filters.

## 1. 核心问题与研究动机

- **背景**：人形机器人走向家庭、仓库、医院等非结构化环境，需要全身协调且安全。当前主流架构把「参考生成」（规划器/遥操作/运动生成器）与「执行」（RL 全身跟踪策略）分离，参考轨迹通常**不编码环境约束**，障碍物、工作空间限制等可能只在运行时出现或事后变化。
- **两条既有安全路线**：
  - 把安全内化进策略（违规惩罚 / 障碍奖励）——需重训练，且不提供运行时保证；
  - 在策略下游加**运行时安全滤波器**（如 CBF-QP），模块化、无需改动标称策略，看似可独立设计。
- **核心发现（本文的问题意识）**：将跟踪策略与安全滤波器**独立设计**会产生闭环内的根本性失配。滤波改变了跟踪器实际执行的动作用与由此诱导的状态分布，而策略是在**无滤波闭环**下训练的，因此出现分布偏移。作者归纳出三类失配：
  - **动力学失配**：CBF 引入内生、自相关的扰动，可能破坏全身协调与平衡（如躯干-CBF 触发后出现急剧前屈、抬膝、接触模式频繁切换，进而增加支撑模型不确定性）；多约束叠加时问题累积。
  - **目标失配**：参考追求与安全可能冲突（参考穿入障碍物），滤波器只能瞬时压制不安全动作，无法引导策略目标；持续的策略-滤波器对抗导致抖动、振荡与颤振；且在松弛 QP 中，更大的不兼容性可能只表现为更大的松弛而非更大的修正，因此单靠修正代价不足以惩罚「送进约束」的提议。
  - **信息失配**：仅靠惩罚无法告知策略「哪些动作方向被当前约束允许」。在障碍物左右放置的两个场景中，在触发修正前策略输入完全相同，无法区分；且需要约束状态与接近速率信息，以及约束信息的历史。
- **整体含义**：论文不是提出新的滤波器，而是**保留已有运行时 CBF 滤波器**，研究如何把预训练跟踪器适配到该滤波器上，并给出「学习型跟踪器 + 运行时安全滤波器」的集成设计原则。

## 2. 方法论：CoFiT（Constrained Filter-aware Tuning）

### 2.1 总体思路
- 保留基座跟踪器的 MLP 结构与原生跟踪奖励作为骨干，**训练与部署全程启用** ConstrainedMimic 全身滤波器；通过注入紧凑约束信息、时序反馈与约束感知惩罚来微调预训练跟踪器，使其**预判滤波干预**并给出协调、约束兼容的运动。

### 2.2 约束上下文观测（解决信息失配）
- 利用策略动作到力矩的映射 τ = B_t a + c_t（目标/力矩裁剪前），代入 CBF 行，得到**动作坐标下的仿射约束**：
  - v_i,tᵀ a + β_i,t ≥ 0，其中 v_i,t = −G_i,t B_t，β_i,t = b_i,t − G_i,t c_t
  - v_i,t 指向「远离约束」的动作方向，β_i,t 是零动作下的约束裕度。
- 观测向量：χ_i,t = [ h_i ; L_f h_i ; β̂_i,t ; v̂_i,t ] ∈ R^{m+3}，帽子表示按 ‖v_i,t‖₂ 归一化；同时包含屏障值（当前间距）与接近速率。
- 这些量 QP 本已计算，**无需额外昂贵微分**；仅选取屏障值最小的**单个约束**（top-1）编码成 e_t（滤波器仍强制所有约束）。该表示不依赖具体几何，可跨任意相对度 2 的 CBF 复用。

### 2.3 时序反馈与策略集成（解决动力学失配）
- 定义反馈修正与动作：Δa_t = (q_cmd − q_prop)/s_a（逐元素除以动作尺度），e_a_t = a_t + Δa_t；用 e_a_{t−1} 作为原生「上一动作」通道，并作为动作速率项 a_t − e_a_{t−1} 的参照，使两者都指滤波后的指令反馈。
- 把最新修正 Δa_{t−1} 追加到原生观测得到 ō_t，并保留 H = 10 帧的 ō_t 与编码上下文 e_t 历史（回合边界重置，存储的上下文嵌入不回流梯度）。
- 当前上下文及其编码历史**加到基座策略第一隐层**；所有新增权重**零初始化**，微调前行为与基座策略完全一致；改动同时作用于 actor 与 critic（各自独立网络）。

### 2.4 策略-滤波器对齐奖励（解决目标失配）
- 三项附加惩罚（在任务空间度量 W_t 下）：
  - r_c = exp(−Δτ_tᵀ W_t Δτ_t / σ²) − 1（滤波修正惩罚，σ 为修正尺度）
  - r_r = min(0, min_{i∈V_t} (b_i,t − G_i,t τ_nom_t))（原始条件惩罚，惩罚「送进约束」的提议）
  - r_s = −max_{i∈V_t} δ*_{i,t}（最大已解松弛惩罚，抑制让障碍条件被松弛）
- 总奖励：r̄_t = r_native_t + λ_c r_c + λ_r r_r + λ_s r_s。
- 惩罚项以「贡献相当」为原则配权；作者选用 r_s（唯一只度量求解器行为而非机器人状态），并指出实践者可另行选择。

### 2.5 滤波器基础（预备知识）
- 相对度 2 的 CBF：位置约束在力矩控制下 L_g h_i = 0，通过中间屏障 h_2,i = L_f h_i + α(h_i) 与条件 L_f h_2,i + L_g h_2,i u + α₂(h_2,i) ≥ 0 施加。
- 球体代理/障碍的间距屏障：h_ij(q) = ‖p_i(q) − c_j‖₂ − r_i − r_j − d_safe。
- 全身 QP：在接触一致模型上最小化 ½Δτᵀ W_t Δτ + λ_QPᵀ δ，s.t. G_t τ ≤ b_t + δ、Δτ = τ − τ_nom_t、δ ≥ 0；W_t 按对接触力、任务/姿态加速度的影响加权修正，解得的滤波力矩再映射回关节目标。

## 6. 主要结论与发现

- **设计洞见（消融结论）**：
  - 仿射约束的**两半必须同时给出**：只有 β̂ 或只有 v̂ 与不给约束信息相当；β̂ + v̂ 组合显著降低训练违规；h 与 L_f h 单独也有帮助但无法说明候选动作如何影响约束；完整包最优，甚至**优于具有完整世界系障碍信息的 oracle 基线**，且收敛更快。
  - 集成接口：attention 与 softmax 训练违规最高；max、top-k（8 行）、top-1 基本并列，选 top-1（更简单且验证更安全）。
  - 历史：约束历史与修正历史**逐项累加均降低违规时间**。
  - 奖励：r_c 贡献最大，加 r_r 有非平凡增益；r_i / r_h / r_s 增益递减且彼此接近——关键在于策略获得「滤波器做了什么」的信号。
- **仿真结论（生成场景，滤波器开启）**：CoFiT 在两个基座上均为最低违规时间与最小修正 RMS。相对 filter-only：TWIST2 违规时间 19.31% → 1.71%（**−91%**），修正 RMS 0.458 → 0.188（**−59%**）；SONIC 14.20% → 11.27%（**−21%**），修正 0.517 → 0.369（**−29%**）。五种方法在两种跟踪器上排序一致（CoFiT < observations-only < penalties-only < filter-only < unfiltered）。CoFiT 指令 TV 最低，残余加速度低于 filter-only。
- **观测与惩罚的分工**：observations-only 在无显式修正惩罚的情况下就学会「少要求修正」，且不增加世界系跟踪误差、还降低残余加速度与 TV；再加惩罚进一步降低违规与修正，代价是跟踪精度下降。
- **硬件结论（Unitree G1，滤波器开启，各 10 次）**：

## 摘要
备份控制屏障函数（bCBFs）利用备份控制器下的有限时域预测，为具有有界输入的非线性系统构造隐式安全集。如同模型预测控制中那样，一个不变的备份集充当终端集，保证在预测时域之外仍能安全延续。然而，到达一个小的终端集可能需要较长的预测时域，从而增加在线预测的成本。本文提出一种在线构造方法，在保持预测时域固定的同时，从沿备份轨迹存储的集合构建一个已认证区域。该方法存储有限的球集合，并将每个新认证的集合连接到备份集或先前存储的球。我们推导出保证在固定备份控制器下这些球与备份集的并集具有前向不变性的条件。这些条件还确保每个存储状态都能在有限时间内到达备份集。所得并集充作一个扩大的终端集，使得能够以更短的预测时域认证安全性。我们为安全控制构建了一个可行的二次规划，并证明随着额外认证集合在线存储，安全性得以保持。四旋翼飞行器上的仿真表明，与标准 bCBF 相比，其能以更短的预测时域安全完成任务。

## Abstract
Backup control barrier functions (bCBFs) construct implicit safe sets for nonlinear systems with bounded inputs using finite-horizon predictions under a backup controller. As in model predictive control, an invariant backup set serves as a terminal set that guarantees safe continuation beyond the prediction horizon. However, reaching a small terminal set may require long prediction horizons, increasing the cost of online prediction. In this paper, we introduce an online construction that builds a certified region from sets stored along backup trajectories while keeping the prediction horizon fixed. The method stores finite collections of balls and connects each newly certified collection to the backup set or to previously stored balls. We derive conditions that guarantee forward invariance of the union of these balls and the backup set under a fixed backup controller. These conditions also ensure that every stored state reaches the backup set in finite time. The resulting union serves as an enlarged terminal set, allowing safety to be certified with shorter prediction horizons. We formulate a feasible quadratic program for safe control and prove that safety is preserved as additional certified collections are stored online. Simulations on a quadrotor demonstrate safe task completion with a shorter prediction horizon than the standard bCBF.

## 摘要
模型预测路径积分（MPPI）控制通过采样并评估轨迹来规划动作，但标准 MPPI 不能保证安全性。将控制屏障函数（CBF）滤波器纳入每次轨迹推演，可使规划器考虑安全修正。然而，通过软最小值近似组合多个 CBF 可能会排除满足原始安全约束的状态，从而限制规划器可用的轨迹。本文提出 Exact-Safe MPPI，它使用多个屏障函数的精确最小值，并在规划和控制执行期间均应用基于 CBF 的二次规划。为处理多个屏障函数同时达到最小值时出现的不可微性，该滤波器同时对全部 δ-活跃屏障施加 CBF 条件，这些屏障的值位于最小值的给定容差 δ>0 内。在适当的可行性与正则性假设下，我们建立了认证安全集的前向不变性，且不引入软最小值平滑所导致的收缩。我们还刻画了依赖于状态的近似差距，并解释了多个屏障函数的值处于或接近最小值时如何增大这种收缩。此外，我们表明，增加 MPPI 采样数量无法恢复被软最小值滤波器排除的轨迹。我们在一个需要穿过两个障碍物之间狭窄间隙的导航任务中验证了所提方法的有效性。视频演示见 https://github.com/lc-lab25/Exact-Safe-MPPI 。

## Abstract
Model predictive path integral (MPPI) control plans actions by sampling and evaluating trajectories, but standard MPPI does not guarantee safety. Incorporating control barrier function (CBF) filters into each rollout allows the planner to account for safety corrections. However, combining multiple CBFs through a soft-minimum approximation can exclude states that satisfy the original safety constraints, restricting the trajectories available to the planner. This paper proposes Exact-Safe MPPI, which uses the exact minimum of multiple barrier functions and applies a CBF-based quadratic program during both planning and control execution. To handle nondifferentiability where multiple barriers attain the minimum, the filter simultaneously enforces the CBF conditions for all $δ$-active barriers, whose values lie within a prescribed tolerance $δ>0$ of the minimum. Under suitable feasibility and regularity assumptions, we establish forward invariance of the certified safe set without the shrinkage introduced by soft-minimum smoothing. We also characterize the state-dependent approximation gap and explain how multiple barriers with values at or near the minimum increase this shrinkage. Furthermore, we show that increasing the number of MPPI samples cannot recover trajectories excluded by the soft-minimum filter. We demonstrate the effectiveness of the proposed approach in a navigation task requiring passage through a narrow gap between two obstacles. Video demonstrations are available at https://github.com/lc-lab25/Exact-Safe-MPPI .

# Exact-Safe MPPI 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：MPPI（模型预测路径积分）是一种基于采样的滚动时域控制方法，通过采样候选控制序列、前向仿真轨迹并施加指数代价权重来更新控制均值。它无需动力学/代价的导数、可并行、能处理非光滑代价，因此在机器人领域广受欢迎。
- **核心痛点**：标准 MPPI **不提供安全性保证**。虽有工作通过在目标中惩罚约束违背或偏置采样来"鼓励"安全，但都不是保证。
- **已有思路及其缺陷**：将 CBF（控制屏障函数）滤波器嵌入每次 rollout（如 GS-MPPI [11]），可让规划器在规划阶段就考虑安全修正，从而避免"规划轨迹与实际执行轨迹不匹配"引起的反复干预、振荡与抖振（chattering）。
- **关键问题**：GS-MPPI 用 **soft-minimum 近似**把多个屏障函数合成单一光滑屏障，即
  `h_ρ(x) = −(1/ρ) ln Σ_j e^{−ρ b_{j,d_j−1}(x)}`。
  由于恒有 `h_ρ(x) ≤ h_min(x) = min_j b_{j,d_j−1}(x)`，soft-minimum 认证集 `H ⊆ D`（D 为精确高阶认证集），**会严格排除掉满足全部原始安全约束的状态**。当多个屏障在"tie"处同时起约束作用时（例如穿越两障碍物之间的窄缝），这种收缩可能直接**堵死可行通道**，且增加采样数量也无法恢复。
- **整体含义**：论文主张用**精确最小值**替代 soft-minimum，配合针对不可微点的非光滑分析处理，在保持 MPPI 采样规划优势的同时，避免认证安全集的人为收缩。

## 2. 方法论

### 2.1 核心思想
- 用精确最小值 `h_min(x) = min_j b_{j,d_j−1}(x)` 表示多约束复合屏障，**不引入光滑化收缩**。
- 由于 `h_min` 在多个屏障并列取最小值处不可微（其 Clarke 广义梯度为活跃屏障梯度的凸包），单一活跃屏障的约束条件不足以保证其余活跃约束，故**同时对所有 δ-活跃屏障施加 CBF 条件**。

### 2.2 关键技术细节
- **高阶 CBF 递归**（处理相对度 d_j > 1）：`b_{j,i+1} = L_f b_{j,i} + α_{j,i}(b_{j,i})`，逐层定义中间安全集 `C_{j,i}`；所有约束的最高阶条件共用同一个局部 Lipschitz 的扩展类-K 函数 α。
- **精确高阶认证集**：`D = C ∩ ⋂_j C_{j,d_j−1}`，其中 `C = ⋂_j ⋂_{i≤d_j−2} C_{j,i}`，且 `D ⊆ S_s`（所有精确性论断均相对 D 而言）。
- **δ-活跃集**：`A_δ(x) = { j : b_{j,d_j−1}(x) − h_min(x) ≤ δ }`，`k_δ(x) = |A_δ(x)|`。
- **Exact Safety QP（式 16）**：给定 MPPI 提出的期望控制 v，
  `min_{û, μ̂} ½‖û − v‖² + (γ/2)‖μ̂‖²`
  `s.t. a_j(x) + B_j(x) û + μ̂_j b_{j,d_j−1}(x) ≥ 0, ∀ j ∈ A_δ(x)`，
  其中 `a_j = L_f b_{j,d_j−1} + α(b_{j,d_j−1})`，`B_j = L_g b_{j,d_j−1}`。松弛项采用乘性形式，在屏障边界 `b_{j,d_j−1} = 0` 处自动消失，因此边界上必须满足**无松弛**的 CBF 条件。

### 2.3 算法流程（Alg. 1）
1. 对 s = 1…K 条 rollout：从当前状态出发，逐 k 步采样扰动 `ε_k ∼ N(0,Σ)`，得到 `v_k = μ_k + ε_k`；
2. 在每个 rollout 步中选取 `A_δ`，求解 QP(16) 得滤波控制 `û_k`，再用 `x_{k+1} = F(x_k, û_k)` 前推；
3. 计算 rollout 代价 `J^(s)`，按指数权重更新均值序列 `μ⁺`；
4. 对 MPPI 输出的 `μ⁺_0` 再执行一次 QP(16)，得到最终执行控制 `û_0`。
- 规划阶段用单步 Euler（步长 T_s），执行阶段用更小的子步 δt 重新评估滤波器。

### 2.4 理论结果
- **Theorem 1（D 的前向不变性）**：在 Assumption 1、QP 在 D 邻域内可行且返回局部有界可测控制/松弛的假设下，闭环 Filippov 解从 D 出发将始终留在 D 内。证明要点：边界上 `h_min(x̄)=0` 使该屏障落入 `A_δ`，松弛项消失后 QP 直接给出无松弛 CBF 条件，再借助比较引理与 Filippov 凸化阻止屏障变负，最后由高阶递归保持所有低阶条件。
- **Theorem 2（tie 局部化的认证集收缩）**：设 `A(x)` 为取到最小值的屏障集合，`k = |A(x)|`，`Γ(x)` 为未并列屏障到最小值的间隙，则
  `h_min − h_ρ = (ln k)/ρ + (1/ρ) ln(1 + (1/k) Σ_{j∉A} e^{−ρ(b_j − h_min)})`，
  且 `ln k/ρ ≤ h_min − h_ρ ≤ ln k/ρ + ((ℓ−k)/(kρ)) e^{−ρΓ(x)}`。
  **含义**：仅在 k ≥ 2 的 tie 附近存在 O(ln k/ρ) 量级的显著间隙；远离 tie（k=1）时间隙指数级衰减。
- **采样无用性**：soft-minimum 滤波器下的 rollout 恒留在 H 内，无法到达 `D \ H`；若最低代价的精确安全轨迹必须穿过 `D \ H`，则任何 soft-minimum 方案存在不可消除的代价间隙 Δ（式 20），**增加采样数无法弥补**。

## 6. 主要结论与发现

1. **安全性**：在可行性与正则性假设下，Exact-Safe MPPI 保证精确高阶认证集 D 的前向不变性，且不引入 soft-minimum 导致的收缩。
2. **理论刻画**：soft-minimum 与精确最小值之间的差距是**状态相关**的，在 k 个屏障并列处为 O(ln k/ρ)，远离并列处指数衰减；因此收缩是非均匀的、集中在多约束同时起作用的位置。
3. **采样无法补救**：soft-minimum 滤波器的支撑集被限制在 H 内，增加 MPPI 采样数不能恢复被排除的 `D \ H` 轨迹，存在持久代价间隙。
4. **实验验证**：所有 1050 次 `κ < ln 2` 的 soft-minimum 运行均**未能穿越窄缝**（最小成功值为 0.875 = 1.26 ln 2），与解析阈值 ln 2 一致；Exact-Safe MPPI 成功穿越且无安全违背（4950 次运行中记录到的最小 `min_j h_j` 为 +2.4×10⁻²）。
5. **δ-活跃同时施加的必要性**：只约束单一最严格屏障会带来安全违背与更强的控制抖振；同时施加全部 δ-活跃屏障在测试中零违背。
6. **大 ρ 的数值隐患**：soft-minimum 在 ρ = 200、1000 时分别出现 34、53 次安全违背，作者归因于屏障 tie 附近数值评估精度下降，而非理论失效。

## 7. 优点

- **问题定位精准**：抓住 soft-minimum 光滑化的"隐性保守性"这一被忽视但实际影响巨大的问题（窄缝场景下直接堵死可行通道），并用图示与解析计算清晰呈现。

- **框架实用**：CBF-QP 在规划与执行两个阶段一致使用，缓解了"规划-执行不匹配"引起的抖振；同时兼容高阶 CBF 与不同相对度约束。
